## 🚀 Featured Projects

Here are some academic and personal projects I've worked on.

### 1. Employee Management System

A web-based employee management application designed to simplify
organizational HR operations.

**Key Features:** - Employee record management - Attendance management -
Leave management - Payroll management

**Technologies:** React, Node.js, Express.js, PostgreSQL

### 2. University Campus Life & Services App

A mobile application designed to improve communication and access to
campus services at Injibara University.

**Key Features:** - Campus announcements and events - Clubs and
organizations - Campus facilities directory - Campus map and location -
Emergency contacts - Service requests and feedback - Push
notifications - Role-based access control

**Technologies:** React Native, Expo, TypeScript, Node.js, PostgreSQL

### 3. Registration Management System

A full-stack registration management application developed around a
Software Requirements Specification (SRS).

**Key Features:** - User registration and authentication - Role-based
access control - User management - Registration workflows

**Technologies:** React, Node.js, Express.js, PostgreSQL

### 4. Hotel Booking Application

An academic mobile application focused on hotel booking workflows and
mobile user interfaces.

**Technologies:** React Native, Expo

### 5. Clinical Management System

A full-stack academic project focused on organizing clinic operations
and managing information through role-based access.

**Technologies:** React, Node.js, Express.js, PostgreSQL
